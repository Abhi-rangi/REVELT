# Revelt – Design Ideas

## Approach 1: Clinical Precision

<response>
<text>
**Design Movement:** Swiss International Typographic Style meets Medical-Tech
**Core Principles:**
- Rigid grid with deliberate asymmetry — content blocks offset to create visual tension
- Typography as the primary design element — large, confident numerals and headings
- Negative space as a luxury signal — generous breathing room communicates premium
- Monochromatic base with single accent — restraint builds trust

**Color Philosophy:** Near-white (#F8FAFB) background with deep navy (#0F2340) text, and a precise teal accent (#0ABFBC) for CTAs and highlights. The palette communicates clinical authority without coldness.

**Layout Paradigm:** Asymmetric two-column sections where text and visuals alternate dominance. Hero uses a large left-aligned headline with a floating UI mockup on the right. Sections break the grid intentionally.

**Signature Elements:**
- Thin horizontal rules that span partial widths, creating visual rhythm
- Large step numbers (01, 02, 03) in light gray behind section content
- Pill-shaped stat badges floating near key claims

**Interaction Philosophy:** Hover states reveal depth — cards lift with subtle shadow, CTAs expand slightly. Scroll-triggered fade-ins that feel inevitable, not flashy.

**Animation:** Staggered entrance animations on text (word-by-word reveal). Cards slide in from slight offset. Counter animations on statistics.

**Typography System:** Sora (headings, bold/800) + DM Sans (body, 400/500). Heading scale: 72px hero, 48px section, 32px subsection.
</text>

## Approach 2: Warm Clinical Luxury ← SELECTED

<response>
<text>
**Design Movement:** Biophilic Wellness Meets High-Tech SaaS
**Core Principles:**
- Warm whites and sage greens create a spa-like calm while UI elements signal technology
- Layered depth — subtle grain texture on backgrounds, frosted glass cards
- Generous vertical rhythm with intentional section breaks using organic dividers
- Contrast between "human warmth" (imagery, rounded forms) and "machine precision" (data tables, metrics)

**Color Philosophy:** Warm off-white (#FAFAF8) base, sage green (#4A7C59) as primary, soft slate blue (#3B5998 → adjusted to #4A6FA5) as secondary accent. Gold (#C9A84C) used sparingly for premium highlights. The palette evokes a high-end wellness brand that happens to use AI.

**Layout Paradigm:** Full-bleed sections with alternating background tones (white → pale sage → white). Hero is split: left-heavy text with right-side floating dashboard UI mockup. Timeline section uses a horizontal scroll-snap on mobile.

**Signature Elements:**
- Frosted glass cards with subtle green-tinted borders
- Organic blob/wave SVG dividers between sections
- Animated gradient mesh in hero background (sage + blue + white)

**Interaction Philosophy:** Everything feels "spa-smooth" — 400ms ease transitions, no jarring snaps. Hover states use color temperature shifts (slightly warmer on hover). CTAs pulse gently to draw attention.

**Animation:** Hero text fades in with a gentle upward drift. Comparison table rows reveal sequentially. Service cards fan in from center. Stats count up on scroll entry.

**Typography System:** Playfair Display (headings, italic accents) + Plus Jakarta Sans (body). Creates the editorial luxury feel of a premium wellness brand.
</text>

## Approach 3: Dark-Mode Tech Authority

<response>
<text>
**Design Movement:** Dark SaaS Dashboard Aesthetic — "Bloomberg Terminal meets Calm"
**Core Principles:**
- Deep charcoal backgrounds (#0D1117) with luminous accent colors signal serious tech
- Data visualization as decoration — mini charts, sparklines, and metric cards everywhere
- High contrast typography — white headlines pop against dark surfaces
- Glowing accent elements suggest AI activity and live processing

**Color Philosophy:** Near-black (#0D1117) background, electric teal (#00D4AA) primary accent, soft blue (#4A9EFF) secondary. Subtle purple gradients (#6B46C1) in hero mesh. Communicates cutting-edge AI technology.

**Layout Paradigm:** Full-width dark sections with floating card clusters. Hero uses a centered layout with a large animated gradient orb behind the headline. Sections use card grids with glowing borders.

**Signature Elements:**
- Animated gradient orbs/blobs in hero and CTA sections
- Glowing border cards with subtle inner glow on hover
- Terminal-style text animations for key stats

**Interaction Philosophy:** Hover states trigger glow intensification. CTAs have a subtle pulse animation. Scroll reveals use a "scan line" effect.

**Animation:** Typewriter effect on hero headline. Particle/dot grid animation in hero background. Cards materialize with a blur-to-sharp transition.

**Typography System:** Space Grotesk (headings) + Inter (body). Technical, modern, no-nonsense.
</text>
