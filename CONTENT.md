## Color Palette

Defined in `client/src/index.css` (OKLCH). Primary buttons and accents use **blue** → **teal** gradient.

| Token | OKLCH | Use |
|-------|--------|-----|
| **Navy** | `oklch(0.25 0.04 250)` | Headlines, dark text, footer/stats background |
| **Navy light** | `oklch(0.35 0.05 250)` | Body text, secondary copy |
| **Blue** | `oklch(0.50 0.15 240)` | Primary buttons, borders, ring/focus |
| **Teal** | `oklch(0.55 0.12 195)` | Accents, highlights, stats, eyebrow labels |
| **Off-white** | `oklch(0.98 0.004 250)` | Page background, primary foreground on dark |
| **Light gray** | `oklch(0.96 0.008 250)` | Cards, secondary background |
| **Border / Input** | `oklch(0.90 0.012 250)` | Borders, form inputs |
| **Muted foreground** | `oklch(0.45 0.03 250)` | Muted text, captions |
| **Destructive** | `oklch(0.577 0.245 27.325)` | Errors, destructive actions |

**Gradient:** `linear-gradient(135deg, var(--blue) 0%, var(--teal) 100%)` — used for CTA sections and primary buttons.

**Approximate hex reference:** Navy `#1e2a3a`, Navy light `#2d3d52`, Blue `#2563eb`, Teal `#0d9488`, Off-white `#fafaf9`, Light gray `#f0f0ee`.
